# A Library of Smart Contracts for Decentralized Exchages Designed to Reduce Impermanent Loss 

Библиотека смарт-контрактов децентрализованных бирж для снижения непостоянных потерь поставщиков ликвидности. 

#### Аннотация: 
Поставщики ликвидности на децентрализованных биржах несут риск непостоянных потерь при изменении рыночной цены активов. Для снижения этих потерь проект реализует библиотеку настраиваемых смарт-контрактов на базе Uniswap v4 с двумя механизмами для пулов ликвидности: 

1. Динамические комиссии. Перед обменом (before swap) хук рассчитывает динамическую комиссию с учётом состояния рынка и параметров сделки. 

2. Встроенный арбитраж. После обмена хук проверяет возможность арбитража по заранее заданным маршрутам и, если операция выгодна, исполняет её в той же транзакции. Полученная прибыль направляется поставщикам ликвидности или протоколу. 

#### Цель: 
Снижение непостоянных потерь поставщиков ликвидности через внедрение настраиваемых хуков в децентрализованных биржах

#### Задачи:  
- Реализовать хуки динамической комиссии в рамках библиотеки
- Реализовать хуки интернализации MEV в рамках библиотеки
- Продемонстрировать существование режимов рынка, при которых хуки Динамической комиссии снижают непостоянные потери 
- Продемонстрировать существование режимов рынка, при которых хуки интернализации MEV снижают непостоянные потери 

#### Результаты: 
- Реализованы хуки динамической комиссии в рамках библиотеки
- Реализованы хуки интернализации MEV в рамках библиотеки
- Продемонстрировано существование режимов рынка, при которых хуки Динамической комиссии снижают непостоянные потери 
- Продемонстрировано существование режимов рынка, при которых хуки интернализации MEV снижают непостоянные потери 
- Продемонстрировано, что гибкая настрока политик интернализации арбитража позволяет балансировать между комиссией сети и фактически извлекаемой ценностью (MEV), находя точку максимального выигрыша при заданных условиях рынка. 
Это будет график: MEV(gas). Технически - разное количество маршрутов.
