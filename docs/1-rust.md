### Rust-инструмент поиска MEV 

Краткое описание: 
Делаем CLI на Rust — офлайн-инструмент для одного целевого Uniswap v4-пула. Он локально на форке блокчейна отбирает и ранжирует арбитражные маршруты (циклы), содержащие этот пул, и формирует конфигурацию самых прибыльных маршрутов, которые будут проверяться он-чейн. 

Вход: 
- Пара токенов `token0` / `token1` и их количество (именно пул из этих токенов мы хотим потенциально создать) 

Прицип работы: 
1. Берем входную пару токенов, находим все уже задеплоенные пулы Uniswap V4 с такой же парой токенов. Если что, пул на Uniswap V4 однозначно определяется  через (token0, token1, fee, tickSpacing, hooks). Выбираем `INPUT_POOLS_COUNT` из них (берем те, которые без хука). 
2. Делаем форк состояния блокчейна ровно во время `HISTORY_TIMESTAMP` (условно - 2026-10-01 00:00:00). Из наших найденных пулов отбираем `INPUT_POOLS_COUNT = 1` пул, который ближе всего по состоянию токенов к нашим параметрам. 
3. Отбираем `TOP-N` транзакций по величине изменения цены в пуле после нее. Транзакции смотрим в окне `WINDOW_TIME`. 
4. Для каждой транзакции прогоняем after-swap логику: извлекаем MEV через reference пулы по найденным маршрутам (подробнее - ниже).
